How to use this page. Every example here uses a made-up library system (loans.dat, books, members), not NALEDI. Learn the technique, then build your own NALEDI modules with your own structure, names and wording. Section B is marked by running your system, and near-identical scripts between students are referred for collusion. The examples were tested with GNU bash, awk and date.

1. Safety header, lock, temp files and audit all of B

#!/usr/bin/env bash
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
TMP="$(mktemp -d)"
cleanup() { rm -rf "$TMP"; }
trap cleanup EXIT                                   # runs on every exit path
trap 'echo "interrupted" >&2; exit 130' INT TERM    # exit triggers the EXIT trap

with_lock() { ( flock -x 9; "$@" ) 9>"$ROOT/data/.lock"; }   # serialise data writes

audit() {   # audit ACTION TARGET OUTCOME [DETAIL]
  printf '%s|%s|%s|%s|%s|%s\n' "$(date -Is)" "$(id -un)" "$1" "$2" "$3" "${4:-}" >> "$ROOT/logs/audit.log"
}
  • The lock is released automatically when the subshell ends, even if the process is killed, because the kernel drops it with the file descriptor.
  • date -Is gives ISO-8601 with the time zone.
  • Call it as with_lock register_animal "$tag". Keep the audit call inside the locked function so the log and the data always agree.

2. Validation recipes B2, B4

A real calendar date, not in the future

valid_date() {   # dd-mm-yyyy
  local s=$1 iso
  [[ $s =~ ^([0-9]{2})-([0-9]{2})-([0-9]{4})$ ]] || return 1
  iso="${BASH_REMATCH[3]}-${BASH_REMATCH[2]}-${BASH_REMATCH[1]}"
  [ "$(date -d "$iso" +%F 2>/dev/null)" = "$iso" ] || return 1   # round trip rejects 31-02
  [[ "$iso" > "$(date +%F)" ]] && return 1                      # not in the future
  return 0
}

Tested: 31-02-2025 and 29-02-2027 are rejected, 29-02-2024 is accepted, 1-1-2020 is rejected by the format check. The round trip works because date either refuses an impossible date or rolls it over, and either way the output no longer equals the input. For B4, also compare against the date of birth: two ISO strings compare correctly with [[ "$a" < "$b" ]].

Closed sets and patterns

in_set() { local x=$1; shift; local i; for i in "$@"; do [ "$i" = "$x" ] && return 0; done; return 1; }
in_set "$sex" M F || echo "Sex must be M or F" >&2
[[ $surname =~ ^[A-Za-z][A-Za-z' -]*$ ]] || echo "Surname has invalid characters" >&2
cut -d'|' -f1 "$ROOT/data/districts.dat" | grep -qx "$district" || echo "Unknown district" >&2

Decide the national identity number format yourself and state it in the report. Validation never writes anything: finish every check first, then write once.

3. Sequential IDs that are never reused B2

next_seq() {   # call inside with_lock
  local f="$ROOT/data/.tag_seq" n
  n=$(( $(cat "$f" 2>/dev/null || echo 0) + 1 ))
  echo "$n" > "$f"
  printf '%s%05d\n' "$TAG_PREFIX" "$n"
}

Do not use "highest tag in the file plus one". When an animal moves to the Mortality Register, that method hands its tag out again. A counter that only goes up never does.

Defining a duplicate

is_duplicate() {   # key built from the fields YOU decide identify "the same item"
  local key=$1 file=$2
  awk -F'|' -v k="$key" '($2 "|" $5 "|" $6 "|" $7)==k {f=1} END{exit !f}' "$file"
}

The paper gives you the fields (owner NID, DOB, sex, breed, within the same village). Your report must say how you defined it and why, so explain what you chose not to match on, such as the tag, which is always new.

4. Search and age arithmetic B3, B5

# exact match on field 1
awk -F'|' -v k="$tag" '$1==k' "$file"

# partial, case-insensitive on field 2, aligned table, with a count and a not-found message
awk -F'|' -v q="$term" '
  BEGIN { printf "%-10s %-14s %s\n", "TAG", "SURNAME", "VILLAGE" }
  index(tolower($2), tolower(q)) { printf "%-10s %-14s %s\n", $1, $2, $3; n++ }
  END   { if (n) printf "%d record(s) found\n", n; else print "Nothing found" }' "$file"

Tested: searching mok returns both Mokoena and MOKGOSI. Use index() rather than a regex so a user typing a dot or bracket cannot break the search.

Age in whole months at a date you supply

age_months() {   # age_months BIRTH ASOF, both YYYY-MM-DD
  local by bm bd ay am ad
  IFS=- read -r by bm bd <<<"$1"; IFS=- read -r ay am ad <<<"$2"
  echo $(( (10#$ay-10#$by)*12 + 10#$am-10#$bm - (10#$ad < 10#$bd ? 1 : 0) ))
}
age_months 2024-08-25 2026-02-25    # 18
age_months 2024-08-26 2026-02-25    # 17

The 10# prefix stops bash reading 08 and 09 as bad octal numbers. Age is calculated from the date of birth each time and is never stored.

5. Atomic transfer between two files B4

move_record() {   # run under with_lock. Moves one line from SRC to DST
  local key=$1 src=$2 dst=$3 ns nd
  grep -q "^$key|" "$src" || { echo "Not found: $key" >&2; return 1; }
  ns=$(mktemp "$src.XXXXXX"); nd=$(mktemp "$dst.XXXXXX")        # same directory, so mv is a rename
  awk -F'|' -v k="$key" '$1!=k' "$src" > "$ns"                  # source without the record
  { cat "$dst"; grep "^$key|" "$src"; } > "$nd"                 # destination plus the record
  [ -z "${NALEDI_FAIL_TEST:-}" ] || { rm -f "$ns" "$nd"; echo "forced failure" >&2; return 1; }
  chmod --reference="$src" "$ns"; chmod --reference="$dst" "$nd" # mktemp makes files mode 600
  mv "$nd" "$dst" && mv "$ns" "$src"                           # destination first
}
  • Both new versions are built completely before any live file changes, so a failure at any point before the renames leaves both files exactly as they were.
  • Renaming the destination first means a crash between the two renames can only create a duplicate, never lose a record. Add a startup check that reports a tag present in both files.
  • Demonstrate it for the report: run once with NALEDI_FAIL_TEST=1, then show wc -l and sha256sum of both files before and after. They must match.
  • Reject a second death record by checking the mortality file first, and reject a permit for any tag found there.

6. Non-interactive mode and the menu B1

# Translate long options, then use getopts. The clerk menu and the scheduler call the SAME functions.
args=(); for a in "$@"; do
  case $a in --run-compliance) args+=(-r);; --sweep-permits) args+=(-s);; *) args+=("$a");; esac
done
set -- ${args[@]+"${args[@]}"}
while getopts ":sr:h" o; do case $o in
  s) with_lock sweep_permits; exit $? ;;
  r) with_lock run_compliance "$OPTARG"; exit $? ;;
  h) echo "usage: naledi [--sweep-permits] [--run-compliance YYYY-MM]"; exit 0 ;;
  :) echo "Option -$OPTARG needs a value" >&2; exit 2 ;;
  *) echo "Unknown option" >&2; exit 2 ;;
esac; done

while true; do
  clear; show_counts                                   # live counts on every redraw
  read -rp "Choice: " c || break                       # end of input must leave the loop
  case $c in
    1) if ! register_animal; then echo "Not saved. See message above."; fi ;;
    q|Q) break ;;
    *) echo "Invalid choice" ;;
  esac
  read -rp "Press Enter" _ || break
done

Trap: under set -e a failing function would drop the clerk out of the menu. Calling it inside if ! fn; then prevents that. A count such as active animals is one line of awk: awk -F'|' '$10=="ACTIVE"{n++} END{print n+0}' file (check the field number in Appendix A).

7. Permits and the expiry sweep B6

sweep_loans() {   # dd-mm-yyyy due date in field 4, status in field 5
  local today out; today=$(date +%F); out=$(mktemp "$ROOT/data/loans.dat.XXXXXX")
  awk -F'|' -v OFS='|' -v t="$today" '
    { split($4, d, "-"); iso = d[3] "-" d[2] "-" d[1] }
    $5=="OPEN" && iso < t { $5="EXPIRED"; print $1, $2 > "/dev/stderr" }
    { print }' "$ROOT/data/loans.dat" > "$out"
  chmod --reference="$ROOT/data/loans.dat" "$out"; mv "$out" "$ROOT/data/loans.dat"
}

Only OPEN rows are changed, so a second sweep on the same day finds nothing and changes nothing. Compare file hashes before and after the second run to prove it. For the expiry date, add the validity from config with date -d "$iso + $PERMIT_DAYS days" +%F, then write it back as dd-mm-yyyy with date -d "$iso" +%d-%m-%Y. Each refusal must say its own reason: not ACTIVE, already holds an OPEN permit, or which district is under QUARANTINE.

months_in_default() {   # consecutive months, a first offence is 1
  local tag=$1 ym=$2 n=1 prev
  prev=$(date -d "$ym-01 -1 month" +%Y%m)
  while [ -f "$ROOT/data/defaulters_$prev.dat" ] && grep -q "^$tag|" "$ROOT/data/defaulters_$prev.dat"; do
    n=$((n+1)); prev=$(date -d "${prev:0:4}-${prev:4:2}-01 -1 month" +%Y%m)
  done
  echo "$n"
}
penalty=$(( PENALTY_BWP * $(months_in_default "$tag" "$ym") ))

reopen_month() {   # deliberate, confirmed and logged
  read -rp "Type REOPEN $1 to confirm: " c
  [ "$c" = "REOPEN $1" ] || { echo "Cancelled"; return 1; }
  audit REOPEN "$1" OK; mv "$ROOT/data/inspection_${1/-/}.dat" "$ROOT/data/inspection_${1/-/}.dat.reopened"
}

Quarantine on the 25th means checking EffectiveFrom and EffectiveTo against that date, not against today. Prevent a double inspection by checking the Inspected flag before you set it.

9. Report once, show it twice B8

build_report_data() {   # one pass, writes district|qualifying|inspected|defaulted|pct|penalty
  awk -F'|' -v OFS='|' '
    { q[$3]++; if ($6=="Y") i[$3]++ }
    END { for (d in q) { df=q[d]-i[d]; printf "%s|%d|%d|%d|%.1f\n", d, q[d], i[d]+0, df, 100*(i[d]+0)/q[d] } }
  ' "$1" | sort > "$TMP/report.psv"
}
# table view and CSV both read $TMP/report.psv, so nothing is computed a second time
column -t -s'|' "$TMP/report.psv"
{ echo "District,Qualifying,Inspected,Defaulted,Compliance,Penalty"; tr '|' ',' < "$TMP/report.psv"; } > "$out.csv"

The tested output looks like D1|2|1|50.0. Add the penalty total from the defaulters file and a totals row in awk. Round with %.1f, and guard against a district with zero qualifying animals before you divide.
